## Prvo pokretanje aplikacije

1. U root direktorijumu projekta pokrenuti:

```bash
npm install
```

- Ovo će instalirati potrebne Node dependency-e za root i frontend

2. Nakon toga, startovati i frontend i backend istovremeno komandom:

```bash
npm run start
```
